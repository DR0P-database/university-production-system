# ПР №3. Модель учебных данных и проекции

ПР №3 использует тот же набор, из которого строятся три лабораторных отчёта. Из `coursework/` запусти [общий стенд](../README.md) и затем выполни `./pr3/check.sh`.

## Реляционная модель

[Базовый DDL](../1_lab/sql/schema_from_pr3.sql) описывает университет, институты, кафедры, специальности, группы, студентов, курсы, лекции, материалы, расписание и посещаемость. Связь кафедр и специальностей хранится в связующей таблице. Группа ссылается на направление и выпускающую кафедру, курс включает занятия, расписание связывает тему с группой и датой.

Посещаемость хранится в PostgreSQL. Ключ `(week_start_date, schedule_id, student_id)` исключает повторные отметки, а внешний ключ проверяет соответствие недели занятию. Понедельник учебной недели служит ключом партиционирования. `false` означает пропуск, отсутствие записи — незаполненную отметку.

[Дополнение модели](../1_lab/sql/report_data.sql) вводит текст требований к оборудованию и размечает демонстрационные лекции. [Загрузчик](../1_lab/app/dataset.py) создаёт воспроизводимый набор и переносит одни и те же идентификаторы в проекции.

| Хранилище | Что хранится и зачем |
| --- | --- |
| PostgreSQL | Транзакционные факты, справочники, ограничения целостности и недельные партиции. |
| Redis | Карточки студентов как Hash по зачётке. |
| MongoDB | Документ университета с вложенными институтами, кафедрами, специальностями, курсами и темами. ЛР №2 читает требования к оборудованию из этой структуры. |
| Neo4j | Связи студента, группы, расписания, темы и курса. Отмеченные посещения хранятся в PostgreSQL. |
| Elasticsearch | Названия и тексты материалов с русским анализатором. Метаданные связывают найденные материалы с лекциями. |

## Проверка

Контрольный набор содержит 4 группы, 104 студента, 8 курсов, 64 темы, 192 события расписания, 2912 отметок, 16 недельных партиций и 128 материалов. Скрипт читает все пять хранилищ и сверяет размеры проекций с реляционной моделью. Ход аналитических запросов показан в [отчётах ЛР №1–3](../1_lab/REPORT.md).
