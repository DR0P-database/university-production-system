# ПР №2. CRUD в пяти хранилищах

Используй контейнеры из [ПР №1](../pr1/README.md). Из `coursework/` запусти:

```bash
for script in pr2/[1-5]_*.sh; do bash "$script" || exit; done
```

Каждый сценарий создаёт учебное хранилище, записывает данные, читает их по ключу, вносит изменение, удаляет запись и удаляет учебное хранилище.

| Скрипт | Данные и проверка удаления |
| --- | --- |
| [Redis](1_redis.sh) | Hash с ключом-зачёткой. После удаления учебной БД №1 `DBSIZE` возвращает 0. |
| [MongoDB](2_mongodb.sh) | Документ группы со студентами и курсами. После удаления учебная БД отсутствует в списке. |
| [Neo4j](3_neo4j.sh) | Группа, студенты, обязательные и индивидуально выбранные курсы. Удаляются тестовые узлы и ограничения. |
| [Elasticsearch](4_elasticsearch.sh) | Индекс описаний курсов. После удаления индекс отвечает `404`. |
| [PostgreSQL](5_postgres.sh) | Групповые справочники и таблица посещаемости с недельными партициями. После удаления учебная схема отсутствует. |

Примеры используют синтетические данные и запускаются только в учебном Compose-проекте.
