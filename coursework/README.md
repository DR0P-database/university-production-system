## Запуск ЛР №1–3

Нужны Docker с Compose и Python 3.12. Выполни из каталога `coursework/`:

```bash
python3.12 -m venv 1_lab/.venv
1_lab/.venv/bin/python -m pip install -r 1_lab/requirements.txt
./1_lab/scripts/start.sh
```

Локальный [Swagger](http://127.0.0.1:8000/docs) открывается после автоматической загрузки демо-данных. Нажми **Authorize** и используй `admin` с паролем из `1_lab/secrets/demo-credentials.txt`. Примеры запроса каждого отчёта приведены в [инструкции к лабораторным](1_lab/README.md).

Если порт 8000 занят исходным стендом, используй `LAB_GATEWAY_PORT=18000 ./1_lab/scripts/start.sh` и открывай Swagger на порту 18000. Команда `./1_lab/scripts/stop.sh` останавливает лабораторный стенд с сохранением томов.
