# ПР №1. Развёртывание пяти хранилищ

Из `coursework/`:

```bash
docker compose up -d --wait
./pr1/check.sh
```

| Служба | Модель хранения | Локальный порт | Проверка |
| --- | --- | ---: | --- |
| Redis | Ключ — значение | 16379 | `PING`, пути данных и AOF/логов |
| MongoDB | Вложенные документы | 27027 | `ping`, параметры запуска |
| Neo4j | Узлы и типизированные связи | 17474 (HTTP), 17687 (Bolt) | Cypher и настройки каталогов |
| Elasticsearch | Полнотекстовые документы | 19200 | Состояние кластера, настройки путей |
| PostgreSQL | Реляционные таблицы | 15432 | SQL, каталог данных, логирование |

Данные и журналы доступны в `data/` и `logs/`. Основной журнал Elasticsearch доступен через `docker compose logs elasticsearch`. Для завершения работы используй `docker compose down`.
